# Barbearia Kuhn

Site da Barbearia Kuhn, na Av. Independência, 1036, em Santa Cruz do Sul (RS).

Arquivo único (`index.html`) com fotos e logo embutidos. Para publicar, importe este repositório na Vercel (Framework Preset: Other, sem build) ou ative o GitHub Pages (branch `main`, pasta raiz).

A página está marcada como `noindex` enquanto for uma proposta. Antes de publicar como site oficial, remover essa tag e confirmar telefones e autorização de uso das fotos e avaliações.
